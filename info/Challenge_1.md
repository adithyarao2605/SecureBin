@ Legacy Modernisation: PrivateBin

Problem Description

Build a modern, secure, and user-friendly platform for sharing sensitive text and information online, inspired by the core problem addressed by PrivateBin.

The goal is not to replicate PrivateBin or reproduce its existing UI/UX. Instead, participants are expected to understand the underlying problem and develop their own modern interpretation and solution using a suitable contemporary technology stack.

Your solution should cover the essential capabilities required for secure and controlled information sharing, while giving you the freedom to rethink the user experience, architecture, security model, collaboration features, usability, performance, and other aspects.

The provided PrivateBin repository is included as a reference implementation. Participants may clone and explore the repository to understand how the existing system works, but the final solution should demonstrate independent implementation and meaningful innovation.

Reference Repository:
https://github.com/PrivateBin/PrivateBin

Core idea: Understand the problem → preserve the essential purpose → build your own modern solution → innovate beyond the reference.
